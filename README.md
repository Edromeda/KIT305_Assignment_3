# KIT305_Assignment_3

##Target Device
Iphone 17 pro Emulation

##View Controllers
**HouseListViewController** - The main screen, displays houses.

**AddEditHouseViewController** - Screen for adding or editing a house and saves them on Firebase.

**RoomListViewController** - Screen that displays all rooms in a house and the view Quote button that navigates to QuoteViewController.

**AddEditRoomViewController** - Screen for adding or editing a room.

**RoomDetailViewController** - Screen that displays all windows and floor spaces in a room. 

**AddEditItemViewController** - Screen for adding or editing a window/floorplan.

**ProductPickerViewController** - Screen for adding and choosing products for a window/floorplan.

**QuoteViewController** - Displays an itemised quote for the total of a house.
